#### Features
- works for
    - ALB
    - NLB
    - CLB(Classic Load Balancer)
- works thanks to
    - cookies
- cookie types
    - application-based cookies
        - custom cookie
            - generated by target (e.g., ec2 instances, ecs tasks)
            - can include any custom attributes
            - cookie names must be specified for individually for each target group
            - can not use AWSALB, AWSALBAPP, or AWSALBTG (reserved by other cookie options)
        - application cookie
            - generated by the load balancer
            - cookie name will be *AWSALBAPP*
    - durataion-based cookies
        - generated by the load balancer
        - cookie name will be *AWSALB* for ALB, *AWSELB* for CLB
- use cases:
    - in order to keep user's session
    - to route the traffic to the same target
