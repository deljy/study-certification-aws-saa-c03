## Amazon S3 Static Website Hosting
short explanation comes here

### Features
#### general
- S3 offers a way to host static website
    - you can find the way in this step "bucket > properties > static website hosting"
    - you better use offered option instead of configuring setup on your own
    - because, with this aws native option, you can specify the home/default path for your website like index.html
- you should enable the public access
- you'll get bucket website endpoint which might look like
    - https://bucket-name.s3-website-<yourAZ>.amazonaws.com
    - https://bucket-name.s3-website.<yourAZ>.amazonaws.com
