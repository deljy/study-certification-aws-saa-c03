### Features
#### general
- High Performance bucket in one single availability zone storage class
- objects stored in a *directory bucket in a single AZ* instead of the general purpose bucket
- the bucket can handle 100,000 requests per second with single-digit millisecond latency
- up-to 10x better performance than s3 standard with 50% lower cost
- high durability (99.9^9%) and availability (99.95%)
- co-locate your storage and compute resources in the same AZ (which can reduce latency too)
- use cases:
    - latency-sensitive apps
    - data-intensive apps
    - AI & ML traning
    - financial modeling
    - media processing
    - HPC
    - integrated with sage maker model training, EMR, Glue
