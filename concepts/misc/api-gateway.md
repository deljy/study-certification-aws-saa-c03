## [API Gateway][api-gateway]
Create, maintain, and secure APIs at any scale

### Features
#### general
- is a fully managed service that makes it easy for developers to create, publish, maintain, monitor, and secure APIs at any scale. APIs act as the "front door" for applications to access data, business logic, or functionality from your backend services.
- supports HTTP, HTTPS, and WebSocket.
- can be associated with
    - Lambda
        - ELB set up is not needed
    - ec2
    - ecs with ec2/fargate
        - ELB set up is needed
