### Recycle bin
a rule applied to deleted resources like EBS snapshots and AMIs

#### Features
- set up rules to retain deleted resources, in case you delete the resource by accident.
- you can specify retention from 1 day to 1 year.
- you can just take it as a rule to retain deleted resources like "resource recycle bin = a rule".
- application rules can filter deleted resources with specific tags that resources have/had
