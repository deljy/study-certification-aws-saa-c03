## Simple Routing Policy
a type of routing policies that Route53's record can have

### Features
#### general
- route traffic to a single resouce or a multitude of resources
- if multiple values are returned (specified in the record), the client will choose a random value
- when alias option is enabled, only one aws resource is allowed to be specified
- can't be associated with Health Check
