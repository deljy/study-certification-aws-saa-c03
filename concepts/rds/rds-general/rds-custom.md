## RDS Customisation
for oracle db and ms sql server db, you can manage/configure underlying systems like OS and database config.

### Features
#### RDS Custom
- configure settings
- install patches
- enable native features
- **access the underlying EC2 instance via SSH or SSM session manager**
- recommended to **deactivate the automation mode** of RDS.

#### Comparison: RDS vs RDS Custom 
- RDS:
    - entire database and the OS to be managed by AWS. 
- RDS Custom:
    - full admiin access to the underlying OS and the database.
