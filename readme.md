# AWS SAA-C03 Exam Preparation

This repository is created to take notes while preparing for the **AWS Certified Solutions Architect - Associate (SAA-C03)** exam.

- **Exam dumps and notes** from [www.examtopics.com](https://www.examtopics.com/) are stored in the `exam-dumps/` directory.
- **Lecture summaries and key points** from the Udemy course [AWS Certified Solutions Architect Associate SAA-C03](https://www.udemy.com/course/aws-certified-solutions-architect-associate-saa-c03/) are in the `udemy-lectures/` directory.

Feel free to explore and contribute if you find useful insights!
